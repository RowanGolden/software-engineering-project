This is a readme file

I've been using computers since I received a Commodore 64 when I was five years old. All of my interests and hobbies have revolved around computers in some way.

For my first career, I decided to go in a different direction from computers, however, and I joined the U.S. Air Force. After twenty years, I was able to retire, and I wanted to switch my professional focus back towards computers, so, using my GI Bill, I began to pursue a Computer Science degree.

From the Software Engineering class, I hope to learn some of the tools of team project collaboration that are typically used in professional environments.
